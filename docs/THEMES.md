# Themes

Eleven themes, each in its own CSS file under `src-tauri/native/themes/`,
selected by `settings.appearance.theme`. The files are the WebView front end's
theme files, kept in the same shape: `src-tauri/native/src/theme.rs` reads every
plain color token (`#rgb`, `#rrggbb`, `rgba()`) from them at startup and on
every theme change, and sets the Slint `Theme` global of each window. Gradients
and shadows have no Slint counterpart and are skipped. A token a theme leaves
out keeps the darkblue value.

## The contract

A theme file overrides ONLY the colour tokens, inside a single
`:root[data-theme="<name>"]` block. It must not touch radii, type, motion,
spacing, blur or the chevron mask: those are structural and shared, and a theme
that changes them stops being a theme.

**Every theme must define all 36 of these.** Leaving one out silently inherits
the dark value, which is how a light theme ends up with white text on white.

```
surfaces   --bg-0 --bg-1 --surface-1 --surface-2 --surface-3 --surface-4
           --swatch-empty --window-wash
overlays   --overlay-1 --scrim-1 --scrim-2
borders    --border-1 --border-2 --border-3 --window-border
           --border-media-1 --border-media-2
text       --text-1 --text-2 --text-3 --text-bright
accent     --accent --on-accent
ext hues   --ext-1 --ext-2 --ext-3 --ext-4 --ext-5 --ext-6 --ext-7
status     --danger --ok --warn
shadows    --shadow-1 --shadow-2 --shadow-3
```

`--accent-soft`, `--accent-strong` and `--danger-soft` are derived with
`color-mix` from the two above them and must NOT be redefined.

Neither should `--bg`, `--panel`, `--input-bg` and `--hover`: the two window
shells reference those, and `tokens.css` derives them from the surfaces above,
so every theme gets them for free. They were previously referenced with hard
dark literals as fallbacks and defined nowhere, which meant no theme could
reach the window background, the panels or the inputs — a light theme stayed
dark in exactly the places that mattered.

## Rules that make a theme usable rather than merely coloured

- **`color-scheme`.** A light theme must set `color-scheme: light` in its block,
  or the scrollbars and form controls stay dark against it.
- **`--on-accent` is the text drawn ON the accent** — the "right now in buffer"
  badge uses it. Pick it for contrast against your accent, not for harmony.
- **Contrast.** `--text-1` on `--bg-0` needs at least 7:1, `--text-2` at least
  4.5:1. These are read at a glance over a grid of thumbnails.
- **The scrims sit over user content**, not over your background: a photo can be
  any colour, so a scrim must stay dark enough to carry white glyphs whatever is
  underneath, even in a light theme.
- **The seven `--ext-*` hues** label file types and must be distinguishable from
  each other AND from `--accent`, which marks the live clipboard item.
- **Shadows** on a light background need to be softer and less opaque than on a
  dark one; copying the dark values makes a light theme look bruised.

## Adding one

1. Write `src-tauri/native/themes/<name>.css` with one
   `:root[data-theme="<name>"]` block.
2. Add it to `FILES` in `src-tauri/native/src/theme.rs`.
3. Add the name to `THEMES` in `src-tauri/core/src/settings.rs`, which
   validates `appearance.theme`.
4. Add `theme.<name>` to every file in `src-tauri/native/locales/`.

The settings window lists it, with a preview drawn from its own tokens, as soon
as it is in `FILES`. The test `every_theme_defines_the_core_tokens` checks the
tokens the windows cannot do without.

## The set

| name | ground | accent | why it exists |
|---|---|---|---|
| `darkblue` | near-black, cool | `#7aa2ff` | the default |
| `black` | pure `#000` | `#c2c2c2` | OLED |
| `grey` | neutral grey | `#a6a6a6` | nothing saturated but the accent |
| `light` | cool off-white | `#b5b5b5` | daytime |
| `skyblue` | pale steel blue | `#c2e4ff` | light, but not white |
| `dark-green` | deep green | `#40ac3e` | terminal, with taste |
| `dark-purple` | deep violet | `#9630c5` | cool and rich |
| `ember` | warm charcoal | `#ff9e5e` | the only warm dark: least blue light at night |
| `ocean` | teal-navy | `#3ad6d6` | the gap between the blue and the green |
| `wine` | burgundy | `#ff86a8` | warm and red where dark-purple is cool and violet |
| `paper` | ivory, warm | `#954a18` | reads like a page, not a screen |

The last four were generated by `tools/gen_themes.py` rather than written by
hand: surfaces climb in even lightness steps from `--bg-0`, so cards separate
by the same amount in every one of them, and borders and overlays are the text
colour at low alpha, which keeps them tinted with the theme instead of neutral
grey. Scrims stay near-neutral in all four — they lie over the user's own
images, and a warm scrim would colour their photos.
